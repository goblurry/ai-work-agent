# 학사 문의 프론트엔드

React · Vite 학생 화면. 로그인, 문의 유형별 접수, 내 문의 목록·상세, 요청받은 정보 보완, 최종 답변 조회를 배포 API에 연결합니다.

```bash
cd frontend
npm install
npm run dev
```

http://127.0.0.1:5173 에서 확인합니다. 로컬 Vite가 /api 요청을 배포 백엔드로 전달합니다. 개발 프록시에서만 HTTPS 쿠키를 로컬 HTTP에 맞게 변환합니다.

- `src/student`: 학생 화면
- `src/staff`: 담당자 화면
- `src/shared`: API·아이콘·디자인 토큰·공통 스타일

색상 기준: 이화 그린 RGB(0, 70, 42), `#00462a`. 공통 CSS 변수는 styles.css 상단에서 관리합니다.

실제 학교 SSO는 연결하지 않은 시연용입니다. 계정은 별도 안내된 학생 계정을 사용합니다. 프론트에 API 키와 DB 비밀번호를 저장하지 않습니다. 배포 시 /api 역방향 프록시 또는 VITE_API_URL과 백엔드 CORS 설정이 필요합니다.

학기 입력은 휴학·복학 접수에서만 표시합니다. 휴학·복학을 적용할 학기로, 신청일과 구분됩니다. 다른 유형으로 변경하면 학기 값은 전송하지 않습니다. 담당자가 특정 학기를 요청하면 정보 보완 화면에서 입력합니다.
