# Academic Inquiry Management System

학사 문의 처리 시스템. 학생 문의에 필요한 자료를 검색하고, 행정 담당자의 판단을 반영해 답변 작성을 지원합니다.

## 핵심 기능

- **역할별 로그인**: 학생은 자신의 문의만 조회하고, 직원은 전체 문의와 처리 기능을 이용합니다.

- **문의 접수·관리**: 학생 웹 문의와 직원이 입력한 전화 문의를 저장하고 처리 상태를 관리합니다.
- **유형별 조건 입력**: 졸업·교과과정, 과목 인정, 휴학·복학, 기타 문의에 필요한 학생 조건을 저장합니다.
- **근거 검색**: 관련 문서를 검색하고 학과·입학연도·전공 구분 등 적용 조건을 확인합니다. 학수번호는 정확 조회합니다.
- **Agent 실행**: 검색 결과에 따라 재검색, 정보 보완 요청, 초안 작성 또는 담당자 확인으로 분기합니다.
- **답변 작성·승인**: 담당자 판단과 메모를 반영한 초안을 작성합니다. 담당자가 수정·승인한 최종 답변만 학생에게 표시합니다.
- **처리 기록**: 검색 근거, 실행 과정, 담당자 판단, 최종 답변을 문의별로 보관합니다.

## 처리 흐름

문의 접수 → Agent 검색·조건 확인 → 담당자 검토·판단 → 답변 초안 → 수정·승인 → 최종 답변 조회

조건이 부족하면 보완 후 재실행하고, 초안이 부적절하면 판단을 변경해 다시 작성하거나 직접 수정합니다.

## 기술 구성

| 구분 | 기술 | 용도 |
|---|---|---|
| 프론트엔드 | React | 학생 문의·행정 담당자 화면 |
| 백엔드·Agent | Python · FastAPI | 문의 처리 API·검색 및 답변 작성 흐름 |
| 업무 DB | PostgreSQL(Supabase) | 계정·세션·문의·답변·처리 기록 |
| 문서 검색 | Qdrant Cloud · BGE-M3 | 문서·질문 임베딩 및 관련 근거 검색 |
| 답변 생성 | OpenAI API | 근거와 담당자 판단을 반영한 초안 작성 |
| 백엔드 배포 | Hugging Face Docker Spaces | API·임베딩 모델 실행 |

업무 DB는 Supabase PostgreSQL에 연결합니다. 로컬 테스트에서는 SQLite도 사용할 수 있습니다. Hugging Face 배포는 준비 중입니다.

실행 방법과 주요 API는 [백엔드 README](backend/README.md)를 참고하세요.
