## 학사 행정 담당자용 문의 처리 시스템

- 학생 문의에 맞는 근거 문서 검색
- 담당자 판단을 반영한 학생 답변 초안 작성

<br> 

### 핵심 기능

- **문의 접수**: 학생 웹 문의 · 담당자 전화 문의 입력
- **조건 기반 검색**: 학과 · 입학연도 · 전공 구분 · 적용 시점으로 근거 필터링, 학수번호 정확 조회
- **Agent 처리**: 재검색 · 정보 보완 요청 · 초안 작성 · 담당자 확인으로 자동 분기
- **담당자 판단**: 예 / 아니요 / 추가 확인 선택 + 메모 → 학생 답변 초안 생성
- **승인 후 공개**: 담당자가 수정 · 승인한 최종 답변만 학생에게 표시
- **처리 기록**: 근거 · 실행 과정 · 담당자 판단 · 최종 답변 보관

<br>

### 처리 흐름

```
접수 → 근거 검색 · 조건 확인 → 담당자 검토 · 판단 → 답변 초안 → 수정 · 승인 → 학생 조회
```

| 상태 | 의미 |
|---|---|
| 접수 완료 | Agent 처리 전 |
| 정보 확인 필요 · 학생 보완 대기 | 학생 조건 부족 |
| 담당자 검토 필요 | 근거 불충분 또는 담당자 판단 필요 |
| 초안 준비 | 근거 기반 초안 작성 완료 |
| 답변 완료 | 최종 답변 등록 |

<br>

### 기술 스택

| 구분 | 기술 |
|---|---|
| 프론트엔드 | React · Vite (Vercel) |
| 백엔드 · Agent | Python · FastAPI (Hugging Face Docker Spaces) |
| 업무 DB | PostgreSQL (Supabase), 로컬 SQLite |
| 문서 검색 | Qdrant Cloud · BGE-M3 |
| 답변 생성 | OpenAI API |

<br>

### 구조

```
backend/                 FastAPI · Agent · 배포 스크립트
frontend/                담당자 화면(src/staff) · 학생 화면(src/student)
이화여대_학사행정_RAG/    학사 자료 수집 · 선별 도구
eval/                    평가용 질문 세트
```
