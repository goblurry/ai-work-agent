# 학사나침반 — 공개 학사·행정 자료 기반 RAG 질의응답 에이전트

SNU 빅데이터 핀테크 AI 13기 과제 (Category G) · 한준 · 기훈 · 현선

## 무엇인가
학교 직원(행정실·과사)이 학생 문의에 답할 때 쓰는 **업무 보조 웹앱**.
학칙·학사안내·FAQ·공지·교육과정을 검색해 **근거와 함께 답변 초안**을 만들고,
확정할 수 없으면 사유와 판단자료를 제시한다. 학생에게 직접 회신하지 않는다.

## 왜 기존 것과 다른가
같은 질문도 **학번에 따라, 그리고 규정이 언제 개정됐는지에 따라** 답이 다르다.
- 선행연구(고려대 hoBIT)는 **학번 축**만 다룬다 — 학생용 챗봇
- 법률 RAG 연구는 **날짜 축**만 다룬다 — 사용자 조건 없음
- 우리는 **둘 다** 다루고, **직원이 쓰는 업무 시스템**으로 만든다
